Events & Activities

Here are some of the key activities conducted by the Innovators Club. All events are planned keeping beginners in mind.

Intro to Web Development

A hands-on workshop where students learn the basics of HTML and CSS and create their first simple web page.

Mini Hackathon

A 6-hour team event where participants build small projects and present their ideas to seniors and faculty.

Coding Practice Session

Regular problem-solving sessions to practice C / C++ / Python basics and improve logical thinking.

Tech Talk with Alumni

Interactive guest session where alumni share their journey, internship experiences and tips for students.
